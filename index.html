Itemized List with the Same Text and 6 Different Font Sizes, use Inline Styling - Subheader 5 (Extra Subheader)

    Absoulte Units:

  • Px - Pixels: The most used absolute unit for screens (1px = 1/96th of 1in)
  • Cm - Primarly used in print stylesheeth
  • In - Inches: Primarly used in print stylesheet (1in = 96px = 2.54cm)

    • Relative Units:

  • Em - Relative to the font-size of the parent element
  • Rem - Relative to the font-size of the root HTML element
  • Vw - Relative to 1% of the width of the viewport*. 100vw = full width of the viewport

4 Different Positioning Sizes - Subheader 6 (Extra Subheader)

Static: Default; Goes based on normal flow of document // Example: Writing/Image in a certain part of the page
Relative: Based on how relative the element is to its normal position // Example: Image relative to a section of text
Absolute: Positioned relative to the nearest positioned ancestor // Example: Sidebar menu and when tapped anywhere on the page will open up
